# השוואת מחירים - חנויות ישראל + עליאקספרס

הרצה מקומית: `npm start` ואז http://localhost:3000
בלי משתנה סביבה SERPAPI_KEY האפליקציה עובדת במצב הדגמה. עם מפתח מ-serpapi.com היא מביאה תוצאות אמיתיות מ-Google Shopping ישראל.

פריסה ב-Render: Web Service, Build: `npm install`, Start: `npm start`, ומשתנה סביבה SERPAPI_KEY.
